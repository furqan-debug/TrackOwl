# System Requirements

## The desktop app
The desktop app is what tracks time, activity and screenshots. It runs on:

| System | Requirement |
| --- | --- |
| Windows | Windows 10 or 11, 64-bit. Installer comes as .exe or .msi. |
| macOS | macOS 11.0 (Big Sur) or later. Separate builds for Apple Silicon (M1/M2/M3) and Intel. |

There is no Linux build and there is no mobile app.

## The dashboard
Everything else — settings, people, projects, reports and billing — runs in the browser at **trackowl.io/dashboard**. Any current browser works, and there is nothing to install.

## Permissions the app asks for
On macOS, TrackOwl needs **Screen Recording** permission to capture screenshots during a tracked session. Grant it in **System Settings → Privacy & Security → Screen Recording**, then restart the app. Windows does not ask for this.

## Connection
A connection is not needed while you work. The desktop app records time and activity locally and syncs when the machine is back online.

> [!TIP]
> If screenshots never appear in the dashboard, check the Screen Recording permission first on macOS, and the connection second.
